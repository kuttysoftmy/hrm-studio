# ⚡ HRM Studio

> Built autonomously by **Angela AutoPilot** based on [HRM](https://github.com/kuttysoftmy/HRM).

An interactive visual debugging companion and playground for the Hierarchical Reasoning Model. It translates the abstract, multi-timescale reasoning sequences generated by HRM into an elegant, real-time node graph. AI engineers can visually trace how high-level goals are decomposed into low-level action steps, step through reasoning cycles, manually inject interventions to guide the agent mid-flight, and analyze state changes across different cognitive layers. This transforms a complex backend reasoning engine into an observable, tuneable, and highly intuitive developer experience.

## Tech Stack
React + Tailwind CSS + Vite + React Flow + Zustand + Lucide Icons

## Quick Start
```bash
npm install
npm build
```
